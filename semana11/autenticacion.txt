El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando sus credenciales. Esto permite verificar su identidad antes de acceder a determinadas funciones. Algunas rutas deben estar protegidas para evitar que personas no autorizadas consulten o modifiquen información. De esta manera, se protege la privacidad y la seguridad de los datos. No deben exponerse públicamente contraseñas, documentos de identidad, direcciones, números de teléfono, correos electrónicos, tokens, claves de API ni otros datos sensibles de los usuarios o de la comunidad.
